Interest Calculator PWA

Included:
- index.html: the calculator
- manifest.json: install metadata
- sw.js: offline cache

Calculation:
Simple interest = Principal × (Rate / 100) × Period
- Annual rate: period is days / 365
- Monthly rate: period is days / 30
Total due = Principal + Interest

To use:
1. Host these files on an HTTPS website (for example, GitHub Pages or Firebase Hosting).
2. Open the hosted URL on Android Chrome or iOS Safari.
3. Android: browser menu -> Install app / Add to Home screen.
4. iPhone: Safari Share -> Add to Home Screen.

This starter is a calculator, not a payment tracker. It does not save people's records.
